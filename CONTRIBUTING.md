# Contributing to Jurism

## Bug Reports and Feature Requests

Jurism does not use GitHub Issues  or the Zotero forms for bug reports, feature requests, or support questions, but there is a [Discord server](https://discord.com/channels/627030589488496672/627030590117511179).

## Working with Zotero Code

Jurism is a variant of Zotero, on which it is dependent, but from which it is a separate project.

See [Zotero Source Code](https://www.zotero.org/support/dev/source_code).

See [Jurism Code Repository](https://github.com/Juris-M/zotero).
