# Juris-M

[Juris-M](https://juris-m.github.io/) is a modified version of Zotero, with support for multilingual and legal citation styles.

--------------

For more information on how to use this source code (equally applicable to Jurism, although this is a separate project), see the [Zotero documentation](https://www.zotero.org/support/dev/source_code).
